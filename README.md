## 📖 **NumPy Modules**

### **Module 01: Array Basics** 📊
*Created by: [Friend 1] & [Friend 2]*

This module covers the foundation of NumPy:
- **Creating arrays** from Python lists
- **Special arrays**: `zeros()`, `ones()`, `empty()`, `full()`
- **Sequence arrays**: `arange()` and `linspace()`
- **Array dimensions**: 1D, 2D, 3D, and beyond
- **Reshaping magic**: `reshape()`, `flatten()`, `ravel()`
- **Data types**: `int`, `float`, `bool`, `complex`
- **Fun project**: *Sudoku Board Generator*

👉 [Explore Module 01](./module01_array_basics/)

### **Module 02: Indexing, Slicing & Filtering** ✂️
*Created by: [Friend 3] & [Friend 4]*

Learn how to navigate and extract data from arrays:
- **Basic indexing**: `[start:stop:step]`
- **2D slicing**: Working with matrices
- **Sorting**: `sort()` and `argsort()`
- **Boolean filtering**: Masks and conditions
- **Fancy indexing** vs `np.where()`
- **Adding/removing data**: `vstack()`, `hstack()`, `delete()`
- **Real-world example**: *Forest Measurement Analysis*

👉 [Explore Module 02](./module02_indexing_slicing/)
